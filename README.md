# Hush Web 🎙️

Official landing page and downloads website for **Hush** — voice dictation for Windows that writes like you.

## Overview

A lightweight, zero-build static marketing website featuring:
- Hero showcase with interactive pill UI preview
- Feature highlights and architecture breakdown
- Dynamic usage stats visualization
- Direct download links for Hush Windows installers (NSIS Setup & MSI) with SHA-256 checksums

## Architecture

- Plain HTML5 + Vanilla CSS + Modern Vanilla JavaScript
- Zero build steps or external bundler dependencies
- Compatible with GitHub Pages, Cloudflare Pages, Netlify, and Vercel
