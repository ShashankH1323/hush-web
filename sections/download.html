Is it safe?

Yes. Hush is a small independent app that isn’t yet signed with a paid publisher certificate, so Windows and SmartScreen don’t recognise it yet and may show a caution the first time you run it. That warning is about reputation, not about anything harmful in the file.

If you see the blue “Windows protected your PC” screen, choose More info → Run anyway. If Windows says the file “can’t be opened”, unblock it once with the steps on the right. To be completely sure you got the real file, check its fingerprint below.

If Windows blocks the download

  1. Find the downloaded Hush_1.0.0_x64-setup.exe (usually in your Downloads folder).
  2. Right-click it and choose Properties.
  3. At the bottom of the General tab, tick Unblock, then click OK.
  4. Double-click the file — it now opens and installs normally.

Prefer the keyboard? Paste this into PowerShell instead:

Unblock-File "$HOME\Downloads\Hush_1.0.0_x64-setup.exe"
